# Sortie Val d'Oise  
Projet universitaire - Licence 3 Informatique, CY Cergy Paris Université
Année universitaire 2025-2026

## Description du projet
Sortie Val d'Oise est une plateforme web permettant de recenser, présenter et faciliter la découverte des activités, événements et lieux d'intérêt dans le département du Val-d'Oise.

Les utilisateurs peuvent :
- consulter les activités disponibles
- explorer une carte interactive 
- rechercher des événements et filtrer par ville
- ajouter des activités en favoris
- proposer de nouvelles activités pour enrichir le site

Un espace administrateur permet de gérer les utilisateurs et de valider ou refuser les propositions d'activités.

L'interface propose un mode clair et un mode sombre afin d'améliorer le confort d'utilisation.

## Contexte pédagogique
Ce projet a été réalisé dans le cadre du module **Développement Web** de la **Licence 3 Informatique à CY Cergy Paris Université**.

## Fonctionnalités principales
- Affichage des activités sur une carte interactive (Leaflet)
- Recherche d'événements et filtrage par ville
- Système de favoris
- Comptes utilisateurs avec connexion sécurisée
- Soumission d'activités par les utilisateurs
- Interface administrateur pour la modération et la gestion des comptes

## Technologies utilisées
- **Frontend :** HTML, CSS, Bootstrap, JavaScript
- **Backend :** PHP
- **Base de données :** MySQL
- **Librairies :** Leaflet (carte interactive), PHPMailer (gestion des courriels)
